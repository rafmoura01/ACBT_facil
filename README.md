# ACBT Fácil

Página de entrada do app **ACBT Fácil** dos moradores do Conjunto Habitacional Bandeirante (Belém/PA).

Acesse e instale no celular: https://rafmoura01.github.io/ACBT_facil/

Este repositório guarda só a página de entrada (ícone, nome e instalação). O app em si roda no Google Apps Script, e o código dele fica em backup privado.
